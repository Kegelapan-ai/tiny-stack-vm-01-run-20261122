An entry for the [make.fun bounty "Build a tiny stack virtual machine, 22 November 2026"](https://make.fun/bounty/tiny-stack-vm-01-run-20261122): `main.ts` is a complete, exact interpreter of make.fun's tiny stack ISA — 32-bit wrapping arithmetic, a 256-value stack, calls, 256 words of memory, input/output, and all ten traps with their own exit codes, plus the step and output limits. Dependency-free, deterministic, no caching between instances.
